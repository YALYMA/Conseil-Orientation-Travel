# Photos du site (facultatif)

Le site fonctionne sans photo : il affiche des illustrations originales. **Déposez une photo ici et elle remplace automatiquement l'illustration**
(après reconstruction du site : un déploiement Vercel suffit). Aucun code à modifier.

| Où | Nom du fichier | Format conseillé |
|---|---|---|
| Bannière de l'accueil | `hero/hero.jpg` (ou `.webp`, `.avif`, `.png`) | portrait ~ 1000 × 1200 px |
| Pays | `pays/france.jpg`, `pays/belgique.jpg`, `pays/luxembourg.jpg`, `pays/italie.jpg`, `pays/maroc.jpg` | paysage 4:3, ~ 1200 × 900 px minimum |

Pour un pays ajouté depuis l'administration, utilisez son identifiant (ex. `pays/allemagne.jpg`).

**Conseils**
- Poids : moins de ~ 400 Ko par image (le site les redimensionne, mais un fichier léger accélère la construction).
- Cadrez le sujet au centre : l'image est recadrée (mobile / ordinateur) et un dégradé sombre couvre le bas pour garder le texte lisible.
- **Droits** : n'utilisez que des photos libres de droits (en respectant la licence), achetées, ou que vous avez créées. Pour toute personne reconnaissable, obtenez son autorisation écrite.
- Si plusieurs formats existent pour le même nom, le plus léger est choisi dans cet ordre : webp, avif, jpg, jpeg, png.
